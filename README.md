# Sleep Health and Lifestyle Analysis

## Overview
This project investigates the relationship between sleep health and various lifestyle factors using a real-world dataset. The analysis focuses on how sleep duration is associated with physical activity levels, body mass index (BMI), and stress indicators.

## Dataset
The dataset contains individual-level information including sleep duration, daily step count, BMI category, and stress levels. It is used to explore patterns and differences in sleep behavior across different lifestyle profiles.

## Methodology
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Data visualization to identify trends and group differences  

## Tools and Technologies
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Jupyter Notebook  

## Key Findings
The analysis suggests that physical activity decreases noticeably in higher BMI categories, while sleep duration shows relatively smaller variation. These results highlight the potential impact of lifestyle habits on sleep health.

## Future Work
Future studies may apply machine learning models to predict sleep quality based on lifestyle variables and extend the analysis with larger or longitudinal datasets.
